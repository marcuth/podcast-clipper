# Overlays para Clipes Longos (16:9)

Coloque aqui suas imagens de moldura, template ou marca d'água PNG transparentes ou JPGs com proporção horizontal (16:9).

Exemplo:
- `frame_podcast.png`
- `logo_watermark.png`

Ao configurar `DEFAULT_LONG_CLIP_OVERLAY = "assets/overlays/frame_podcast.png"` no seu arquivo `.env`, o Podcast Clipper aplicará automaticamente essa moldura/overlay em todos os clipes longos gerados.
